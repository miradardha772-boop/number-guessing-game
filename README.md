# 🎮 Number Guessing Game in Python

A simple, interactive command-line Number Guessing Game built with Python.

---

## 📌 Project Overview
In this game, the computer selects a random secret number between **1 and 100**. The player's goal is to guess the number with as few attempts as possible. After each guess, the game gives feedback on whether the guess was **too high** or **too low**.

---

## 🛠️ Python Concepts Used
* **Loops:** `while` loop to keep the game running until the correct number is guessed.
* **Conditionals:** `if`, `elif`, `else` statements to guide the player.
* **Comparisons:** Checking if the guess is greater than, less than, or equal to the secret number.
* **Random Module:** `random.randint()` to generate a unpredictable number.
* **Error Handling:** `try/except` block to prevent crashes if non-numeric inputs are entered.
